# Quaderno di Regia

Web app per gestire i laboratori teatrali: agenda degli incontri, checklist degli esercizi, laboratori (partecipanti, presenze, spettacolo) e libreria di esercizi.

È un'unica pagina (`index.html`) pubblicata con GitHub Pages. I dati non stanno in questo repository: sono nel progetto Firebase personale e si leggono solo dopo il login.
